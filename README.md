# Affirmations App Android

Affirmations App Android adalah aplikasi sederhana berbasis Jetpack Compose yang menampilkan daftar afirmasi dalam bentuk kartu. Aplikasi ini dibuat sebagai implementasi materi **Membuat Daftar yang Dapat Di-scroll**, dengan fokus pada penggunaan `LazyColumn`, `Card`, serta pengelolaan resource string dan drawable.

## Fitur

- Menampilkan daftar afirmasi yang dapat di-scroll.
- Menggunakan `LazyColumn` untuk layout daftar yang efisien.
- Menggunakan `Card` untuk membungkus setiap item.
- Menggunakan resource `string` dan `drawable` dari folder `res`.

- Kotlin
- Jetpack Compose
- Material 3
- Gradle Kotlin DSL

## Cara Menjalankan

1. Clone atau download repository ini.
2. Buka project di Android Studio.
3. Tunggu Gradle Sync selesai.
4. Jalankan aplikasi di emulator atau perangkat Android.
